整套系统怎么跑

1. 填 key

编辑项目根目录的 .env：EMBEDDING_API_KEY 必填（text-embedding-v3）；LLM_API_KEY 用于问答，不填也能做检索。

2. 启动数据库

docker compose up -d
docker compose ps

3. 建库（解析 + 向量化 + 图谱）

python ingest.py

4. 启动网页

uvicorn server:app --host 127.0.0.1 --port 8000

浏览器打开 http://127.0.0.1:8000 。以后新增文档：放进 doc/ 后重新执行 python ingest.py。

数据流

doc/*.docx ── python-docx ─┐
doc/*.pdf  ── MinerU ──────┤→ 分块 → text-embedding-v3 → Milvus(dense)
                           │                    └→ BM25 稀疏向量
                           └→ 实体关系抽取 → Neo4j
查询 → dense + BM25 → RRF 融合 → 图谱扩增 → 大模型回答
